Resume: start a new tmux session using the selected session's native CLI resume id. Only ended sessions with saved resume metadata appear in the list.
Import existing: index native Codex, Claude Code, or Cursor Agent history so it appears under Resume. Original transcripts are read-only and are not copied, moved, or deleted.
Terminal: start your login shell without an AI agent. Commands are never auto-approved, and exiting the shell ends the session.
Open iTerm & Start: new iTerm window running siling run. Requires macOS Automation permission for iTerm if the dashboard is running under LaunchAgent.
Start in background: spawn the tmux session only, no iTerm window. View it here or tmux attach -t <name>.

Terminal

Terminal mode is saved in this browser. Applying a palette changes all open sessions; use a pane's More menu to change only that session.

Enter sends; Shift/Option+Enter inserts a newline. Selecting text copies normally. Codex input automatically returns from history to the live terminal.

Role, priority & manual flags

Notifications

Browser-local policy. Permission is controlled by your browser; the bell in the sidebar enables notifications.

The pane Monitor button requests a five-minute heartbeat from the agent. Silence alone is not proof of failure, and this reminder setting is not a heartbeat watchdog.
