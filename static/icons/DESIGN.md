# SiLing app icon

Generated with the built-in imagegen tool. The final master is
`orchestrator-1024.png`; macOS packaging uses it for the complete ICNS size set.
The approved geometric S mark expresses coordinated intelligent processes.
Pearl-white surfaces, a sapphire-to-violet connecting plane and a midnight-indigo
tile add restrained dimension while preserving the clear silhouette.

Compile and run `scripts/build-app-icons.m` using the commands at its top from
the repository root on macOS to derive the web sizes. Standard icons preserve
alpha; Apple Touch and maskable icons composite onto an opaque graphite
background. The older SVG remains for cached clients; current UI and install
metadata use the new PNG assets.

Final generation prompt:

> Use case: style-transfer. Asset type: refined macOS application icon for SiLing, an intelligent AI orchestration workbench. Edit the reference icon to feel a little more fancy, expressive and exquisitely finished while retaining its minimalist visual identity. Preserve the exact abstract interlocking S silhouette, negative-space diamond, centered proportions, generous breathing room, rounded-square tile and transparent outer margin. Transform the broad white symbol into luminous satin pearl-white ceramic with extremely subtle shallow edge bevels and soft sculptural shading, clean and sophisticated rather than shiny plastic. Give the small blue connecting plane a tasteful flowing sapphire-to-periwinkle-to-violet gradient, with a narrow cool cyan highlight at one edge. Make the tile midnight ink with a quiet deep indigo radial color wash, a restrained fine edge highlight and just a little internal depth. A single soft studio light from upper left creates delicate dimensionality; precision, visual confidence, intelligent technology, beautifully controlled materials. High contrast and crisp readable silhouette at 32px. The symbol stays simple; material and color provide the richness. No added glyphs, nodes, circuits, particles, stars, text, watermark, thick outlines, external glow, bloom, lens flare, rainbow chrome or exaggerated extrusion. Deliver one finished square app icon with actual transparent alpha outside the tile, not a mockup or contact sheet.
