# SiLing app icon

Generated with the built-in imagegen tool. The final master is
`orchestrator-1024.png`; macOS packaging uses it for the complete ICNS size set.
The restrained geometric mark suggests an S-shaped signal flow and coordinated
intelligent processes, with a deep navy tile, ivory strokes and a small blue accent.

Compile and run `scripts/build-app-icons.m` using the commands at its top from
the repository root on macOS to derive the web sizes. Standard icons preserve
alpha; Apple Touch and maskable icons composite onto an opaque graphite
background. The older SVG remains for cached clients; current UI and install
metadata use the new PNG assets.

Final generation prompt:

> Use case: logo-brand. Asset type: finished premium minimalist macOS application icon for SiLing, an intelligent AI agent orchestration workbench. Primary request: a genuinely restrained, elegant, technology-forward icon with the clarity of a carefully designed modern software identity. A flat deep ink navy rounded-square tile carries ONE compact ivory-white abstract geometric symbol: two broad precisely aligned angular strokes interlock to suggest an abstract S-shaped signal flow and a small diamond-shaped negative-space core. The visual metaphor is several intelligent processes becoming one coordinated system. Draw the mark as clean filled geometry with consistent visual weight, subtly softened corners, optical balance, generous breathing room and a distinctive readable silhouette. Small tasteful cool blue accent limited to one short internal plane of the mark; nearly monochrome overall. Absolutely flat graphic design, precise vector-like edges, no lighting effects. Square 1024 by 1024 composition, icon tile centered and occupies 88 percent of canvas, transparent alpha outside its rounded corners. Main symbol occupies about 48 percent of total canvas width and stays fully inside the central maskable safe area. No terminal chevron or underscore, no network balls, no circuits, no brain, no robot, no stock AI sparkle, no lettering or words, no watermark, no gradients, no glow, no bloom, no bevel, no glass, no metallic chrome, no extrusion, no plastic, no shadows, no texture. One single production icon; no presentation board, no mockup.
