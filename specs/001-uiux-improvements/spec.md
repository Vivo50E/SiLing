# Feature Specification: SiLing 工作台 UI/UX 改进

**Feature Branch**: `agent/self-improve-spec-kit-20261005`

**Created**: 2026-10-05（继承 2026-09-27 的 UI/UX 规格）

**Status**: Draft — 需求整理完成，待维护者审阅；不是实现完成声明。

**Input**: 用户要求“用 spec kit 把目前项目的 spec 优化一下”。本次默认整理既有 UI/UX 范围，不扩展成全产品 roadmap，不实施新功能。

**2026-10-05 补充需求**：用户要求为基本完成、短期不再使用的会话增加 Archive。纳入 US1 的下一个独立切片，桌面优先并兼容手机；FR-027–029 / SC-011 为新增目标，尚未实现。下述“归档不停止运行、共享归档状态”为建议默认语义，实施前确认；本次只更新需求，不执行任何会话归档。

## Context and Scope

目标用户是同时管理约 6–12 个 coding-agent / Terminal 会话、并偶尔用手机查看或回复的 Dashboard 操作者。希望快速回答“哪项工作需要我、正在发生什么、下一步能做什么”，而不是重新学习不同面板的操作。

本文是 UI/UX 的唯一当前需求契约；[基线与追踪表](baseline.md)记录已有实现、部分证据和旧编号去向。[2026-09-28 实施报告](../../docs/uiux-implementation-status.md)仍是历史证据，不能代表今天的完整验收。以下 MUST 表示目标行为，**不表示当前版本已满足**。

范围：桌面导航和面板、视觉与 agent 身份、移动端单会话体验、Files、设置、状态反馈和无障碍。不包括新终端引擎、前端框架迁移、原生手机 App、自动执行多 agent 工作流、MCP/FTP/交易集成、公网托管或自动部署。现有浏览器 pane、桌面自动更新和 Spec Kit 插件须保持兼容，不在此重复设计。

故事优先级 P1/P2 是本规格的交付顺序，**不是**面板 P0/P1/P2 标记；Lead 是角色，不是更高优先级。每次实施只选择一个有独立验收边界的故事或子切片。

## User Scenarios & Testing

### User Story 1 - 安全管理桌面会话 (Priority: P1)

操作者从桌面找到目标项目与会话、创建新会话或调整布局，不中断后台工作。

**Why this priority**: 创建错位置、误结束任务或丢失输入，比外观不一致造成的损失更大。

**Independent Test**: 使用 6 个不同类型会话和一个空槽位，仅测试导航、创建与面板操作；不依赖移动页面或新的监控服务。

**Acceptance Scenarios**:

1. **US1-A1 Given** 1280px 桌面宽度和 320px 窄 pane，**When** 展示长中英文标题并打开操作菜单，**Then** 标记、Files、放大和更多操作均可到达，标题不遮挡控件；工作区工具栏不产生横向滚动。
2. **US1-A2 Given** 一个空 pane，**When** 点击或用 Enter/Space 创建，**Then** 立即显示创建中；请求期间切换布局或槽位被占用也不覆盖已有会话。成功后落到可用空位，无空位则保留在会话列表。
3. **US1-A3 Given** 创建失败或结果未确认，**When** 用户返回创建界面，**Then** 保留输入；失败可重试，结果未知先复查会话列表，不能因连点生成重复会话。
4. **US1-A4 Given** 会话正在运行且有未发送草稿，**When** 改变主题、项目筛选或布局，**Then** 会话不中断、草稿不串会话；关闭 pane 只隐藏显示，结束 agent 是另一项明确确认的操作。
5. **US1-A5 Given** Terminal、Codex 新建/恢复和 Claude 会话，**When** 选择复制、多行输入、浏览历史后输入/粘贴或滚动到最新，**Then** 复制内容准确、首字符不丢失、历史可退出；跨行长链接的高亮和打开目标均完整。
6. **US1-A6 Given** 相同 Dashboard 被两台设备打开，**When** 修改项目分组名称或颜色，**Then** 两端获得一致的已保存分组；当前筛选和布局仍各自独立，颜色可预览并输入自定义值。
7. **US1-A7 Given** 含两个项目、两个节点及不同 agent/优先级的 12 个会话，**When** 组合筛选、搜索、收藏布局、保存并恢复工作区，**Then** 仅展示匹配记录，清除筛选恢复全部未归档会话；收藏和恢复保留布局选择，不影响后台运行，Files/待处理入口不会混淆为布局操作。
8. **US1-A8 Given** 某会话的工作已基本完成、短期不再使用，**When** 从 pane 更多或会话列表选择“归档 / Archive”，**Then** 成功保存后从日常列表及当前打开的 pane 收起，不自动补入其他会话；可从独立的“已归档 / Archived”入口搜索、查看已有历史和 Files，并取消归档。归档不是删除、日志搬迁或自动整理项目。
9. **US1-A9 Given** 会话仍在运行、存在未发送草稿，或在另一设备打开，**When** 请求归档，**Then** 清楚提示目标及“仅收起，后台仍运行”；取消不改变任何状态，归档不停止或重启 Agent。各浏览器保留自己已有的草稿，已归档列表显示真实执行/连接状态，仍运行的归档项有可见数量提示；已启用的监控和重要待处理事件不被归档静默关闭。
10. **US1-A10 Given** 刷新页面、重启 Dashboard、跨设备查看或归档保存结果未知，**When** 读取归档状态或取消归档，**Then** 已保存状态一致且可恢复，失败/未知不先隐藏会话或宣称成功；取消归档只回到日常列表，不抢占其他 pane、不自动恢复执行。恢复已结束 Agent 仍需单独的明确操作，并说明能否使用原生会话记录。

### User Story 2 - 手机上查看并回复单个会话 (Priority: P1)

用户从手机查看需要处理的工作，进入一个会话阅读输出、打开产出并回复，再返回原来的列表位置。

**Why this priority**: 缩窄桌面多终端布局不能代替手机阅读与输入流程。

**Independent Test**: 对预置会话列表完成“列表 → 单会话 → 回复 → 返回”；使用已有会话状态，不依赖新的待处理聚合算法。

**Acceptance Scenarios**:

1. **US2-A1 Given** 手机进入 Dashboard，**When** 查看全部或待处理会话并进入一个会话，**Then** 默认是列表和只读输出；显示输出更新时间及截断提示，用户明确选择后才进入交互终端。同一手机页面最多一个交互终端，其他后台任务不停止。
2. **US2-A2 Given** 单会话含草稿，**When** 唤起键盘、旋转屏幕或进入 Files 再返回，**Then** 输入区和发送按钮仍可见，草稿只属于该会话，列表筛选与返回位置保留；支持换行和明确的特殊键操作。
3. **US2-A3 Given** 手机断网或重新连接，**When** 尝试发送或收到不确定结果，**Then** 显示未发送/结果待确认并保留草稿，不静默重发，也不声称已执行；恢复后由用户确认下一步。

### User Story 3 - 清楚理解状态与恢复操作 (Priority: P2)

用户区分执行情况、连接情况和人工标记，知道哪个信息可靠，遇到问题能选择正确的恢复动作。

**Why this priority**: 红灯、静默输出和手动 Done 都不能单独证明 agent 失败或完成。

**Independent Test**: 输入已知的在线、离线、等待输入、已结束和心跳过期样本，核对显示与恢复动作；不启动自动处理器。

**Acceptance Scenarios**:

1. **US3-A1 Given** 远程节点离线但上次状态为工作中，**When** 查看 pane 或待处理列表，**Then** 显示连接离线、执行情况未知、观测来源和时间；不能标成已完成。
2. **US3-A2 Given** 人工选择 Lead/P0/Watching/Blocked/Done，**When** 观测到 agent 活动，**Then** 人工标记不被偷偷改写；帮助说明其语义和现有互斥限制，Done 不等于已验证交付。
3. **US3-A3 Given** 会话等待用户、失败、有未读结果或监控过期，**When** 打开待处理入口，**Then** 每项都有原因、来源、时间和可执行动作；同一事件不重复提醒，查看或确认后清除对应未读状态。
4. **US3-A4 Given** 用户明确启用了 5 分钟心跳且 Dashboard 前台可达，**When** 超过应到时间仍无心跳，**Then** 标为监控过期而非任务失败；安静但未启用心跳的会话不被判卡死。后台休眠或断网后恢复前台立即复查。
5. **US3-A5 Given** 显示连接异常或 agent 已结束，**When** 选择恢复，**Then** 清楚区分重新连接显示、恢复一次执行、重新打开 shell、重启 agent；结果未知时先复查，不盲目重复重启或重放 shell 命令。

### User Story 4 - 看得清且可达的 Files (Priority: P2)

用户从 pane 打开规格、代码或图片，知道文件属于谁、是否可用，并在手机上方便返回。

**Why this priority**: 产出必须容易打开、可信且可读，不能只在终端里留下半截链接。

**Independent Test**: 注册测试 Markdown、代码、图片、失效路径和网页，在深浅主题与手机宽度分别预览，不依赖新移动终端设计。

**Acceptance Scenarios**:

1. **US4-A1 Given** 深/浅主题下的长 Markdown 与代码，**When** 打开 Files，**Then** 正文清晰可读，宽表格和代码在自身区域横向滚动，不撑破页面；桌面支持调整列表/预览宽度，手机支持列表进入预览再返回。
2. **US4-A2 Given** 本地文件、远端快照、未验证网页或失效路径，**When** 查看条目，**Then** 显示来源、用途和可用性；未验证链接不冒充已验证产出，失效项提供原因和重新定位入口。
3. **US4-A3 Given** 会话交付规格文档，**When** 用户查看回复，**Then** 有完整可点击链接，并能从该会话 Files 打开同一产出；没有权限时明确报错，不展示其他会话私有文件。

### User Story 5 - 可理解、可恢复的设置 (Priority: P2)

用户通过分类或搜索找到设置，理解改动影响本浏览器、当前会话还是整个 Dashboard，并能安全恢复默认值。

**Why this priority**: 外观偏好和服务配置混淆，会导致“改了没生效”或意外影响其他设备。

**Independent Test**: 单独测试设置面板的偏好保存、来源显示、无效输入与重置，不依赖其他故事完成。

**Acceptance Scenarios**:

1. **US5-A1 Given** 桌面或手机设置，**When** 查找语言、外观、会话默认值、终端输入、通知、浏览/文件、连接/更新、插件或 About，**Then** 分类/搜索能到达，显示作用域、生效方式、当前版本；敏感连接参数默认遮蔽。
2. **US5-A2 Given** 同一浏览器的外观与语言偏好，**When** 修改并刷新，**Then** 保持选择；存储损坏或不可写时安全回退并说明未保存，不影响会话和草稿。重置只影响指定分组，取消重置不改值。
3. **US5-A3 Given** 用户修改共享的会话默认目录，**When** 保存有效或无效路径，**Then** 在执行端校验且不擅自创建目录；失败保留输入、旧有效配置及未知配置项。显示有效值、来源和是否可编辑，不能宣称未实现的同步已生效。
4. **US5-A4 Given** 设置由启动参数覆盖或需要重启，**When** 用户尝试修改，**Then** 显示覆盖原因/生效时机；服务级修改需明确保存，不能把浏览器即时预览当作服务保存成功。

### User Story 6 - 统一视觉、语言和无障碍 (Priority: P2)

用户通过形状、文字与颜色识别 agent；使用深浅主题、中文/英文或键盘时都能操作同样的功能。

**Why this priority**: 统一身份和控件语义能减少重复学习，不能以装饰效果牺牲阅读与可操作性。

**Independent Test**: 使用已知/未知 agent、长名字和弹窗样本，逐一切主题/语言并走键盘路径，无需增加业务功能。

**Acceptance Scenarios**:

1. **US6-A1 Given** Claude/Codex/Cursor/Terminal/未知 agent，**When** 查看列表、pane、新建和通知，**Then** 同种 agent 采用一致的名称和非仅颜色的标识；未知名称安全显示，不冒充官方品牌标志。
2. **US6-A2 Given** 中文/英文/跟随系统、深/浅/跟随系统、紧凑/舒适密度和减少动态效果设置，**When** 切换，**Then** 首方控件与提示统一语言；会话原文不翻译；背景透明度不降低文字透明度，100% 完全不透明，滚动条跟随主题。
3. **US6-A3 Given** 只用键盘或屏幕阅读器，**When** 新建会话、打开 Files/设置/更多菜单并关闭弹窗，**Then** 控件有名称、焦点可见，焦点限制在最上层弹窗并回到触发处；Escape 不同时关闭多层，无拖动也能移动 pane。

### Edge Cases

- 创建请求超时但执行端已创建：按 US1-A3 先复查，不把未知当失败自动重试。
- 两设备同时编辑分组：不得损坏保存内容或静默丢掉无关分组；冲突展示最新值并允许重试。
- 切换设备/退出会话：浏览器偏好不承诺跨设备同步；草稿不得串到另一个会话。
- 权限被拒、远程节点离线、文件被移动：保持页面可返回，错误明确指向失败动作，不泄露凭据或私有路径。
- 长标题、中文换行、超长 URL、未知 agent、空列表、大输出：保留完整可复制值，输出有边界/截断说明；不把终端抓屏称为完整语义对话历史。
- 发送请求结果未知、终端不支持某组合键：不得悄悄丢字符或重复执行；提示限制和可用替代入口。
- 手机后台暂停和系统通知权限被拒：不承诺持续后台计时或推送；恢复前台复查并标明未覆盖时段。
- 归档与取消归档并发、远端离线或旧节点不支持：不得伪装保存成功、错误归档其他会话或触发远端重连/停止；离线设备恢复连接后重新读取权威状态。多个会话共用一个 run 目录时，只操作选中的会话记录。
- 已归档会话被普通轮询、自动填充或旧工作区快照发现：不自动回到日常列表/占据 pane，也不重启；用户明确取消归档后才能重新放入 pane。查看归档输出不等于取消归档。

## Requirements

### Functional Requirements

- **FR-001**: 工作台 MUST 提供新建、搜索、项目/节点/agent/状态/优先级筛选；保存/恢复工作区、布局收藏、Files、待处理与设置入口有明确分工，不重复建设已有总览。（US1、SC-001）
- **FR-002**: Pane MUST 以任务名、agent 和状态为首要信息，保留标记、Files、放大及更多入口；长标题不能遮挡操作，辅助信息可渐进展开。（US1-A1、SC-001）
- **FR-003**: 空 pane MUST 支持点击和键盘创建、请求期间占位及确定失败重试；布局竞争按空位/会话列表降级，未知结果先核对，已有 pane 不得被覆盖。（US1-A2/A3、SC-002）
- **FR-004**: 视觉/布局/筛选操作 MUST 保留会话和草稿，不触发无关的终端重连；隐藏、结束、恢复与重启 MUST 明确区分且危险操作显示目标名称。（US1-A4、US3-A5、SC-002）
- **FR-005**: Terminal、Codex 新建/恢复、Claude MUST 保留复制、直接输入、多行输入、历史阅读和完整跨行链接能力；历史输入首字符不得丢失，滚到最新可退出历史。（US1-A5、SC-003）
- **FR-006**: 项目分组及颜色 MUST 在同一 Dashboard 设备间共享，支持自定义颜色预览；当前筛选和布局属于各浏览器，编辑冲突须可恢复。（US1-A6、SC-002）
- **FR-007**: 手机 MUST 默认任务列表 → 单会话只读输出，保留全部/待处理筛选、返回位置及输出更新时间；显式进入交互后最多保留一个交互终端，不能停止其他后台会话。（US2-A1、SC-004）
- **FR-008**: 手机 MUST 提供会话隔离的多行草稿、发送和 Esc/Tab/Ctrl+C 等明确辅助操作，适配键盘、安全区和旋转；不影响桌面布局偏好。（US2-A2、SC-004）
- **FR-009**: 断网、超时及发送结果未知 MUST 保留草稿、显示不确定性，并禁止未经用户确认的自动重发；“已受理”不能写成“已执行”。（US2-A3、SC-004）
- **FR-010**: 系统 MUST 区分角色、人工优先级/标记、执行情况与连接情况，并展示观测来源、时间及推断性质；未知保持未知。（US3-A1/A2、SC-005）
- **FR-011**: 待处理入口 MUST 聚合等待输入、失败、未读结果和已启用监控的过期事件，包含原因/来源/时间/动作；同事件去重且允许确认。（US3-A3、SC-005）
- **FR-012**: 心跳监控 MUST 是显式启用的契约；分别展示最近状态、输出和心跳时间。5 分钟未收到约定心跳标记监控过期，不能据此断言 agent 失败，也不能把普通静默当卡死。（US3-A4、SC-006）
- **FR-013**: 恢复入口 MUST 区分显示重连、恢复执行、重新打开 shell 与重启 agent，保留可追踪的原会话；未确认结束时不得重复重启，shell 不重放旧命令。（US3-A5、SC-005）
- **FR-014**: Files MUST 支持桌面可调列表/预览、手机列表/详情返回、路径/来源及外部打开；Markdown、代码和图片可读，宽内容只在局部滚动。（US4-A1、SC-007）
- **FR-015**: Files MUST 区分参考资料与交付物、已验证文件/远端快照/未验证网页/不可用资源；权限按来源会话保留，失效原因可见。（US4-A2/A3、SC-007）
- **FR-016**: 文档交付 MUST 提供可点击的完整链接，并绑定到正确会话的 Files；改变规格存放位置 MUST 保留旧文档入口。（US4-A3、SC-007）
- **FR-017**: 设置 MUST 有分类、搜索、桌面分组导航及手机列表/详情导航，覆盖 US5-A1 的分类；每项标注本浏览器/当前会话/整个 Dashboard 作用域和生效方式。（US5-A1、SC-008）
- **FR-018**: 浏览器偏好 MUST 即时反馈并持久化，损坏/不可写时安全回退并提示；分组重置需确认，不能连带清空草稿或会话。（US5-A2、SC-008）
- **FR-019**: 服务设置 MUST 仅允许已授权的可编辑项，显式保存、保留未知项、失败不部分覆盖；默认目录在执行端验证，不自动创建目录，敏感字段不进入通用读取结果。（US5-A3、SC-008）
- **FR-020**: 设置 MUST 显示有效值、来源、覆盖原因及是否需要重启；会话目录的产品默认值为用户 Workflows 目录，用户/节点覆盖必须可辨识。（US5-A3/A4、SC-008）
- **FR-021**: 更新与连接反馈 MUST 显示当前/目标版本、阶段、失败原因和下一步；验证、批准、应用分别呈现，未知结果不能显示成功，错误不能只藏在标题。（US3-A5、US5-A1、SC-005）
- **FR-022**: 同类 agent MUST 在列表、pane、新建、详情和通知采用一致文字/形状身份，颜色仅辅助；未知 agent 保留安全的原名称，角色/优先级不混作 agent 身份。（US6-A1、SC-009）
- **FR-023**: 外观 MUST 提供系统/深/浅主题、舒适/紧凑密度、字体大小、减少动态效果及背景透明度；100% 不透明且文字不随背景变淡，终端配色允许独立选择。（US6-A2、SC-009）
- **FR-024**: 首方控件、空态、错误、确认和设置 MUST 支持中文/英文/跟随系统，未知系统语言回退英文；不得自动翻译 agent 输出或用户命名。（US6-A2、SC-009）
- **FR-025**: 图标控件 MUST 有可访问名称、键盘焦点和非 hover 操作途径；弹窗有正确语义、焦点圈定/恢复和最上层 Escape 行为，移动 pane 有非拖动途径。（US6-A3、SC-010）
- **FR-026**: 普通文字对比度 MUST 至少 4.5:1；手机主要触控目标至少 44×44 CSS px；关键状态不能仅用颜色传达。（US2、US6、SC-010）
- **FR-027**: 桌面 pane 更多、会话列表及手机会话详情 MUST 提供手动归档入口；归档状态独立于人工 Done、执行状态及 pane 布局，只针对选中的会话记录。默认列表/搜索、自动填充和旧布局恢复 MUST 排除已归档会话；清除普通筛选不取消归档。归档 MUST 保留现有日志、原生恢复标识、Files 关联、名称、分组、人工标记及各浏览器已有草稿，不删除/移动原文件，不自动启动整理 Agent。停止执行与归档是分开的操作，运行中或执行未知时须提示并确认。（US1-A8/A9、SC-011）
- **FR-028**: 系统 MUST 提供可发现的“已归档”列表与数量，支持按名称、项目和 Agent 查找，展示归档时间、真实执行/连接状态、仍运行数量和已有输出/Files。取消归档 MUST 只回到日常列表，不覆盖 pane 或自动创建/恢复/重启执行；历史不完整或无法恢复时说明原因，不把日志当作完整原生对话。操作同时有中文/英文及键盘/手机入口。（US1-A8/A10、SC-011）
- **FR-029**: 归档状态 MUST 持久化并由连接同一 Dashboard 的设备共享；在线前台客户端在正常同步周期（不超过 5 秒）收到成功保存的变更，各自只收起对应显示、保留本地草稿和其他 pane 布局。重复请求不得产生额外副作用；并发冲突、保存失败/未知、远端离线或旧节点不支持时 MUST 提示并复查，不能先销毁显示或自动启动/停止会话。关联会话不批量联动；显式恢复产生的新执行默认未归档，原记录仍保留归档身份和关联。启用中的监控/重要待处理事件不因归档被静默关闭。（US1-A9/A10、SC-011）

### Key Entities

- **Session / Execution attempt**：逻辑会话与一次执行尝试分开；恢复产生新尝试但保持可追踪关联。Pane 是展示位置，不是会话本体。
- **Project group / Workspace view**：分组属于 Dashboard；当前筛选、布局和外观属于浏览器。编辑分组不移动或终止后台任务。
- **Observation / Manual flag / Attention event**：观测包含来源、时间与可信范围；人工标记表达用户意图；待处理事件可确认且去重。历史数据不能被新鲜显示掩盖。
- **Preference / Service setting**：偏好有作用域与持久化结果；服务设置另有有效值、来源、编辑权限和生效时机。
- **Artifact**：可打开资源及用途、来源会话/主机、可用性或验证时间；登记网页并不证明网页可达或内容可信。
- **Draft**：当前浏览器中某会话尚未确认发送的输入；草稿与发送结果独立，不能因显示重连自动重放。
- **Archive state**：所选会话记录的显式收纳状态与归档时间，与运行/结束、人工 Done 和 pane 是否打开正交。同一 Dashboard 共享，清除筛选不改变；取消归档不等于恢复执行。原生新执行/关联会话不自动继承旧记录的归档状态。

## Assumptions

- 本次采用既有 UI/UX 规格范围，新增量化门槛为拟定验收标准，待维护者审阅；没有伪造用户对新门槛的批准。
- 保留现有认证、会话和共享分组能力；状态展示先兼容已有人工标记互斥规则。本规格**不要求**立即迁移为可同时保存角色/优先级/标记的新数据结构，迁移需单独规格。
- 每个故事可针对现有能力独立验证；移动故事可复用已有状态，状态故事可先在桌面验证，不相互阻塞。故事不是一次性大版本承诺。
- 5 分钟心跳只保证前台可达条件下的过期可见性，不承诺手机后台常驻；监控过期与 agent 卡死是不同结论。
- 真实 iOS Safari/PWA 与 Android Chrome 的键盘、旋转、复制和重连验收是移动交付门槛；桌面模拟尺寸不替代真机证据。
- 桌面 6–12 会话是验收规模，不是系统容量上限。性能计划需在同一设备、相同会话和网络条件记录前后数据；本次未生成性能结论。
- 各新增切片仍需各自的实现计划及授权；本次 Archive 补充不改写已交付手机阅读切片的 `plan.md`、`tasks.md` 或验收记录，也不执行归档实现阶段。
- Archive 首批为手动、逐会话操作，不按静默时长或人工 Done 自动归档，不包含批量清理、压缩/移动历史或新建历史存储。保留已有内容不代表复制一份完整记录，也不保证已结束 shell 能恢复原内存状态。
