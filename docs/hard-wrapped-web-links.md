# 终端硬换行网页链接修复

日期：2026-09-28。

## 问题与根因

Claude Code pane 中长授权链接点击后只打开前半段。既有逻辑支持 OSC 8 原生链接和 xterm 自动换行，但 CLI 主动插入的换行没有 `isWrapped` 标记。旧的硬换行补偿只针对括号内本地路径，未覆盖裸 HTTP(S) 链接。

用脱敏样例复现：215 字符的授权链接被拆行后，旧实现只打开第一段；新的回归断言在修复前失败。未访问或保存用户提供的真实授权链接。

## 修复范围

- `agent_orchestrator/terminal_theme.py`：在已有的上下各 24 行扫描范围内识别裸 HTTP(S) 连续片段。硬换行要求相同缩进，上一段距终端行尾不超过 8 列，续行只含 URL 字符；遇到空行、带空格的说明文字、另一 URI、缩进变化或短行即停止。原生 OSC 目标仍优先。
- 拼接保留查询参数和百分号编码，不解码或重新编码。点击每一段得到相同完整地址；缩进与行尾填充不算链接区域，高亮只绘制可见部分。
- `tests/terminal_links.cjs`：40、64、90 列、Claude 鼠标策略、外部／内部打开、屏外前缀、误拼接边界、OSC 优先和拖选回归。
- `tests/terminal_browser.mjs`：独立 tmux/ttyd 中输出脱敏硬换行 URL，用真实浏览器点击各段并检查目标；拦截打开操作，不访问授权服务。
- 中英文 README 和本报告：说明范围及限制。

## 验证

完整 unittest **264/264 通过**，Python 3.13.5，warnings-as-errors，无跳过。真实终端浏览器检查通过：跨行高亮和完整目标、直接输入、跨屏滚动选择复制、本地文件链接。Dashboard 浏览器回归和独立 Terminal 创建／接入／输入／停止冒烟通过。Python 编译、逐文件 shell 语法、示例 JSON、最终 inline JS、测试脚本语法和 diff 检查通过。

测试使用隔离进程和样本数据，没有重启用户 Agent，也没有做真实 Atlassian OAuth 授权。真实终端样例复现 CLI 输出及 Claude 鼠标策略，不等于对每种 Claude CLI 输出格式的完整验收。

## 限制与交付

没有原生链接元数据时，硬换行判断仍属于有边界的启发式：自定义窄内容区、很宽的右侧留白、已被省略号裁剪的内容，或紧邻且无法区分的纯 URL 字符文本，不能保证恢复正确。无法判定时应复制完整原链接；不补造缺失字符。

按 SiLing 流程在隔离 worktree 验证并推送自有 main，运行更新另行批准。批准更新后，对受影响 pane 使用「重连显示」加载新的终端页面脚本即可，不需要重启 Agent session。测试日志与截图已绑定当前 task 的 Dashboard Files。
